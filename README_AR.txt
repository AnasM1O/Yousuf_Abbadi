موقع المستشار يوسف عبدالوهاب العبادي
====================================

طريقة التشغيل على Windows:

1) فك ضغط ملف Yousuf_Abbadi_Website.zip بالضغط عليه كليك يمين ثم Extract All / استخراج الكل.
2) افتح المجلد الناتج. يجب أن ترى ملف package.json ومجلدي client و server.
3) اضغط كليك مرة واحدة على شريط العنوان أعلى المجلد، حيث يظهر مسار المجلد.
4) اكتب cmd مكان المسار واضغط Enter.
5) في النافذة السوداء اكتب الأمر التالي واضغط Enter:

   npm install

6) بعد انتهاء التثبيت اكتب:

   npm run dev

7) افتح المتصفح واكتب:

   http://localhost:3000

مهم:
- لا تفتح ملف index.html بالضغط المزدوج؛ يجب تشغيل السيرفر بالأوامر السابقة.
- يجب تثبيت Node.js إصدار LTS أولًا من: https://nodejs.org/
- لإيقاف السيرفر اضغط Ctrl + C داخل النافذة السوداء.

ملفات التعديل الأساسية:
- client/src/pages/Home.tsx
- client/src/index.css
